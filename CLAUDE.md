# Revisión con Claude

Antes de trabajar, leer y aplicar `AGENTS.md` en la raíz del repositorio. Si no está disponible, detener la revisión hasta disponer de la guía compartida.

Rol inicial: revisor independiente, sin editar archivos ni ejecutar comandos que cambien el proyecto o el entorno. Leer el parche y el contexto relevante; proponer comprobaciones sin instalar dependencias automáticamente.

Entregar hallazgos concretos con prioridad, archivo y línea, impacto, evidencia y corrección sugerida. Separar defectos comprobados de dudas. Si no hay hallazgos, decirlo junto con el alcance y las limitaciones. Identificar el commit o parche revisado.

Usar la cuenta Claude Pro ya existente. No cambiar la autenticación a API ni habilitar consumo adicional automáticamente.
